# Benchmark Plan: outbox-pattern

## Hypothesis

The transactional outbox pattern recovers all messages when the system fails after writing to the outbox table but before publishing to the message broker. lost_messages_under_failure = 0.

## Command

```bash
docker run --rm outbox-pattern benchmark
```

- repetitions: 1 per run
- warmup: none
